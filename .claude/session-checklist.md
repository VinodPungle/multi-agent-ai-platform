# Session Checklist

## Before Coding
- Read CLAUDE.md
- Read project-spec.md
- Read architecture.md
- Read engineering-handbook.md
- Review current milestone
- Inspect repository status
- Identify active branch

## Planning
- Confirm milestone scope
- List impacted components
- Identify risks
- Check ADR impact

## Before Commit
- Run formatters
- Run lint
- Run tests
- Update documentation
- Suggest commit message
